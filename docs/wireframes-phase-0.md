# Sketsa Lima Layar Inti

## Beranda

```text
[Sudah rapi hari ini]                 [sembunyikan]
+------------------------------------------------+
| Saldo akun                    Rp3.245.000       |
| Posisi bersih                 Rp3.310.000       |
+------------------------------------------------+
[Pemasukan] [Pengeluaran] [Piutang | Utang]
[Anggaran bulan ini ================== 82%]
Transaksi terbaru                                  [+]
```

## Input

```text
Tambah pengeluaran
Rp [________________]
[Pengeluaran] [Pemasukan]
Akun [Tunai v]   Kategori [Makan v]
Tanggal [hari ini]  Catatan [opsional]
[                 Catat pengeluaran                 ]
```

## Split Bill

```text
Total Rp120.000        Bagian saya Rp40.000
[Sama rata] [Nominal] [Persentase]
(S) Saya              Rp40.000
(A) Ani                Rp40.000  sisa Rp25.000
(B) Budi               Rp40.000  sisa Rp40.000
Jumlah Rp120.000       Selisih Rp0
[                    Simpan tagihan                 ]
```

## Perlu Ditinjau

```text
Perlu Ditinjau (3)
[bukti sintetis]  Jumlah belum terbaca [!]
Ditemukan transaksi mirip. Periksa sebelum menyimpan.
[Edit] [Tolak] [Simpan sebagai transaksi/split bill]
```
