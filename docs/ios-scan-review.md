# Scan dan rincian struk iOS

- Navigasi bawah memakai empat tujuan dan tombol Scan di tengah. Tinjauan tersedia dari ikon baki di Beranda dan halaman Scan. Area tombol minimal 44 pt; label mengikuti Dynamic Type.
- Scan dibuka dalam layar penuh, Struk terpilih, kamera aktif secara default. QRIS memakai kamera pendeteksi QR. Kedua mode menyediakan galeri; Struk juga menyediakan PDF, maksimal tiga halaman dan 5 MB. Kamera berhenti ketika tampilan kamera dilepas, aplikasi tidak aktif, atau hasil ditampilkan.
- Struk menampilkan pratinjau sebelum pembacaan. Akun nyata menggunakan endpoint `receipt-scan` yang sama dengan web, setelah pemberitahuan pemrosesan eksternal. Gambar dikompres menjadi JPEG maksimal 1.300.000 byte per halaman, maksimal tiga halaman. Tidak ada API key penyedia di aplikasi.
- Scan normal iOS dan web memakai endpoint cloud `receipt-scan` dengan sesi akun, bukan Mac atau alamat LAN. Koneksi seluler maupun Wi-Fi lain dapat digunakan setelah backend produksi dikonfigurasi dan dideploy. Mode Demo tidak menyediakan endpoint AI publik tanpa autentikasi. iOS menawarkan masuk akun dari pratinjau foto jika konfigurasi cloud tersedia; foto dipertahankan. API key penyedia tetap di backend.
- Scanner pengembangan lokal hanya dipakai jika dipilih secara eksplisit: launch argument iOS Debug `--local-receipt-scan`, atau `VITE_LOCAL_RECEIPT_SCAN=true` pada web development. Default aplikasi tidak memakai scanner Mac. Test browser memakai flag ini untuk respons mock, bukan API berbayar.
- Jalankan `npm run scan:ios --prefix apps/web` pada Mac, kemudian build ulang iOS Debug. Konfigurasi pasangan dibuat otomatis pada `apps/ios/Configuration/NativeScan.xcconfig` yang diabaikan Git. Mac/iPhone harus berada di Wi-Fi privat yang sama; izinkan Jaringan Lokal pada iPhone. Server hanya mengikat satu alamat IPv4 privat pada port 5174, menolak origin browser, memerlukan token, dan tidak mengembalikan secrets. Tidak ada perubahan ATS yang mengizinkan HTTP atau semua server.
- Server tetap perlu aktif saat scan; setelah server dihidupkan ulang sertifikat/token berganti dan aplikasi Debug perlu dibangun ulang. Hentikan server dengan Ctrl+C. Untuk memilih antarmuka tertentu, gunakan `npm run scan:ios --prefix apps/web -- --host=alamat-IP-Mac`. Ini bukan server publik/produksi. Release tidak memuat kredensial pasangan dan tidak memakai endpoint pengembangan; akun nyata tetap memakai endpoint Supabase terautentikasi.
- Foto dan semua PDF struk memakai AI, tanpa toggle OCR/AI. QRIS dan teks tempel tetap diproses lokal. Parser OCR lama hanya dipertahankan untuk kompatibilitas dan pemulihan draft historis. Kegagalan layanan tidak menjalankan OCR baru diam-diam. Informasi pemrosesan foto berada di Pengaturan / Kebijakan privasi.
- Detail review menyimpan dan menampilkan `receipt`: nama, tanggal, jumlah, harga satuan, total tercetak, catatan, subtotal, service, pajak, diskon, pembulatan, total, bagian belum terbaca, serta selisih. Decoder menerima angka dari endpoint scan maupun string desimal dari penyimpanan web. Nilai `null` tidak diubah menjadi nol.
- Tanggal `YYYY-MM-DD` dibaca dalam zona Asia/Jakarta, bukan diganti tanggal hari ini. Tanggal tidak valid atau hilang diberi peringatan; tanggal draft menjadi nilai awal formulir yang dapat dikoreksi.
- Koreksi menyimpan review yang sama tanpa membuat transaksi. Total yang tidak cocok tidak diperbaiki diam-diam. Pencatatan masih membutuhkan tindakan pengguna; selisih memerlukan konfirmasi tambahan. QRIS hanya untuk pencatatan, bukan pembayaran.
- Draft OCR lama tanpa barang dapat dipulihkan dari teks buktinya saat dibuka, tanpa unggah atau biaya API. `Baca ulang` menawarkan kamera/galeri/PDF untuk memperbarui draft yang sama. Foto tersebut dipakai untuk ekstraksi; lampiran asli tidak diganti. Jika pembacaan gagal, hasil lama tetap tersedia.
- Navbar custom merupakan satu-satunya navbar; tidak lagi melapisi `TabView` native. Tombol Scan berdiameter 60 pt, ikon 27 pt, dengan ruang menonjol 16 pt. Safe area bawah ditutup latar navbar. Tab yang dikunjungi mempertahankan state navigasi; tab tidak aktif tersembunyi dari sentuhan dan aksesibilitas. Banner Demo atas dihapus; status Demo tetap tersedia di Pengaturan.
- Tinjau draft menampilkan rincian dan ringkasan struk tanpa panel Pemeriksaan angka. Penanda baris serta konfirmasi selisih saat pencatatan tetap berlaku. Editor web menampilkan rincian koreksi dalam disclosure, bukan panel sukses yang panjang.
- Split bill menerima rincian serta biaya, diskon, pembulatan, tanggal dan total struk sebagai nilai awal. Penjagaan selisih total tetap berlaku.

## Verifikasi

`swift test --package-path apps/ios` menjalankan tes kontrak dan parser lokal pada macOS. `sh tests/swift/typecheck.sh` memeriksa seluruh sumber aplikasi dan XCTest/UI test. Pengujian kamera, izin, galeri, navigasi, Dynamic Type, dan tata letak native harus dijalankan di simulator/perangkat dengan runtime iOS yang tersedia. Tes mock bukan bukti akurasi ekstraksi foto nyata.

Fixture `tests/fixtures/receipt-retail-ocr.txt` memuat teks OCR dari screenshot pengguna: dua barang, subtotal Rp 361.000, diskon Rp 175.000, total Rp 186.000, tanggal 29 Juni 2025. Fixture `receipt-retail.json` memuat hasil web sebagai acuan kontrak. Tes native backend memastikan payload/prompt dan hasil mock sama dengan handler web, pin/token/Host/TLS, batas gambar dan cache. Tes tersebut tidak mengirim foto pengguna ke penyedia.
